# PyTorch para Deep Learning

Este repositorio contiene los laboratorios, código y recursos del curso **PyTorch para Deep Learning**.

## 🛠️ Requisitos e Instalación

Este proyecto utiliza [`uv`](https://github.com/astral-sh/uv) como gestor de paquetes y entornos virtuales.

### 1. Sincronizar el entorno virtual
Para crear el entorno e instalar todas las dependencias declaradas en `pyproject.toml`:

```bash
uv sync
```

### 2. Estructura del Proyecto

```text
├── M1/
│   └── Lab1/
│       ├── C1_M1_Lab_1_simple_nn.ipynb  # Laboratorio: Red Neuronal Simple
│       └── helper_utils.py               # Funciones auxiliares para gráficas y métricas
├── .gitignore
├── pyproject.toml
└── README.md
```

## 🚀 Uso con Jupyter Notebooks
Puedes seleccionar el entorno `.venv` dentro de VS Code, JupyterLab o tu IDE preferido para ejecutar los cuadernos interactivos (`.ipynb`).
